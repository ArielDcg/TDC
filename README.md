# Técnicas de control para un aeropéndulo
## Control
Carpeta con el código de MATLAB y simulaciones correspondientes

- **ComparacionKUF** 
    Código para contrastar con *PruebasKUF* y comparar la simulación con las pruebas experimentales

- **PruebasKUF** 
    Archivo de simulink para comparación entre el modelo matemático y las pruebas experimentales
- **SimulinkPrueba**
    Simulación definitiva
